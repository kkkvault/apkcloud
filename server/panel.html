APK 롱플레이

이 패널은 네 PC에서만 열린다. 클라우드 분 제한이 없다. PC가 켜져 있고 에뮬레이터가 돌아가는 동안은 시간 제한 없이 플레이할 수 있다. 단, PC를 끄거나 잠들게 하면 에뮬레이터도 멈춘다.

1. 에뮬레이터 상태

아직 확인하지 않았다. 먼저 Android Studio에서 가상 기기를 실행해라.

에뮬레이터가 안 보이면: Android Studio > Device Manager에서 Pixel 기기를 만들고 Start를 눌러라. 처음 부팅은 몇 분 걸릴 수 있다.

2. APK 업로드하고 설치하기

패키지명:

패키지명은 웹 APK 플레이어의 앱 정보에서 복사하거나, 설치 후 “설치된 앱 목록”에서 찾아서 입력해라.

APK를 선택해라.

3. 플레이

설치 후 “앱 실행”을 누르면 에뮬레이터에서 앱이 켜진다. “scrcpy 화면 열기”를 누르면 PC 화면에 안드로이드 화면이 별도 창으로 떠서 마우스/키보드로 조작할 수 있다. 그 창이 진짜 플레이 화면이다. 시간 제한이 없다.

아이폰에서 같은 WiFi로 오래 플레이하고 싶으면 Linux 서버용 Docker 루트를 써라 (README의 Docker 부분). Windows 에뮬레이터 화면 자체는 브라우저 스트리밍이 아니라 scrcpy 창이다.
