APK Cloud LITE - 사이트 안에서 다 해결하는 허브

준비물은 저사양 PC 하나면 끝이다. 실제 안드로이드 태블릿도, 폰도, 별도 서버도 필요 없다. 이 사이트 안에서 APK 분석, 웹APK 재생, PC 사양 확인, pc-lite 다운로드까지 다 한다. 네이티브 게임의 진짜 실행만 PC 프로그램(pc-lite 가상 태블릿)이 맡는다. 블루스택과 같은 방식이다.

APK 파일을 여기에 드롭하거나 클릭해서 선택

.apk 파일만 지원합니다. 용량이 클수록 분석이 오래 걸릴 수 있습니다. (권장 500MB 이하)

아직 파일이 없습니다. 샘플 버튼을 누르면 실제 APK 없이도 플레이 방식을 바로 확인할 수 있습니다.

CONVERT - APK를 PC 실행 파일로 바꾸기

APK 코드를 Windows exe 코드로 바꾸는 게 아니다. 그런 변환은 소스 코드 없이 안 된다. 이 변환은 APK 파일 + 가상 태블릿 실행기(run-app.bat)를 담은 PC 실행 패키지(zip)를 만든다. PC에서 압축을 풀고 pc-lite 폴더에 넣고 run-app.bat을 더블클릭하면, 저사양 PC 가상 태블릿이 켜지고 APK가 설치되고 실제로 실행된다.

아직 변환 안 했다. 먼저 위에서 APK를 선택해라.

주의: pc-lite 설치(setup-lite.bat)가 먼저 끝나 있어야 한다. Roblox는 공식 Windows 클라이언트가 더 낫다. 출처를 모르는 APK는 변환하지 마라.

웹앱 형태 APK가 아니면 플레이 버튼이 활성화되지 않습니다. 아래 안내를 확인하세요.

사이트 안에서 다 해결하기 - 저사양 모드

연결이 필요 없다. 이 사이트에서 1) APK를 분석하고, 2) 웹APK면 바로 재생하고, 3) 네이티브면 pc-lite를 받아서 저사양 PC 가상 태블릿으로 실행한다. 서버 주소 입력도, 클라우드 토큰도 없다.

내 PC 사양 (이 브라우저가 알려주는 범위만)

아직 확인 안 했다.

pc-lite 받기

apkcloud 레포 열기 - Code 버튼에서 Download ZIP을 누른다
ZIP을 풀면 pc-lite 폴더가 있다. 순서: lite-check.py 확인 - 구글 공식 Command line tools zip을 같은 폴더에 넣기 - setup-lite.bat - play-lite.bat. Roblox는 플레이어의 Roblox 버튼으로 공식 Windows 클라이언트를 바로 실행한다.

HTML 웹사이트 안에 안드로이드 OS를 담아서 무거운 3D 게임을 돌리는 것은 현재 웹 기술로 안 된다. 브라우저는 하이퍼바이저와 GPU를 블루스택처럼 직접 쓸 수 없다. 그래서 사이트는 분석, 재생, 다운로드, 안내까지 맡고, 진짜 실행은 저사양 PC 프로그램이 맡는다.

저사양 모드 안내 - 솔직한 한계부터

브라우저 안에서는 안드로이드 네이티브 코드(DEX)를 직접 실행할 수 없습니다. 그래서 이 허브는 분석 + 에셋 미리보기 + 웹앱 APK 실제 플레이 + 사양 확인 + pc-lite 다운로드까지는 사이트 안에서 하고, 네이티브 앱의 진짜 실행은 저사양 PC 가상 태블릿(pc-lite)으로 연결합니다.

저사양 PC에서 네이티브 APK 실행하기
1. apkcloud 레포에서 pc-lite 폴더를 저사양 PC에 복사한다.
2. setup-lite.bat으로 경량 태블릿(lite, 1280x800, RAM 1024MB)을 만든다.
3. play-lite.bat에서 APK 선택, 설치, 실행, scrcpy 화면 순서로 한다.
Roblox
1. 에뮬레이터가 필요 없다.
2. 공식 Windows 클라이언트를 설치하고 pc-lite 플레이어의 Roblox 버튼으로 실행한다.
3. 저그래픽 설정이 저사양 PC에 유리하다.
브롤 같은 무거운 3D 게임
1. 경량 태블릿으로 켜지고 조작되는 것이 목표다.
2. 고그래픽, 고프레임은 하드웨어 한계로 보장할 수 없다.
3. 출처를 모르는 APK는 설치하지 마라.

이 사이트는 어떤 APK도 서버에 업로드하지 않습니다. 분석, 해시 계산, 플레이가 모두 이 브라우저 안에서 일어납니다.
