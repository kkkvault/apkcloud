APK Cloud LITE - 똥컴용 로컬 가상 태블릿

연결이 필요 없다. 준비물은 똥컴 끝이다. 실제 안드로이드 태블릿도, 폰도, 별도 서버도 필요 없다. 이 사이트에서 받는 PC 프로그램이 똥컴에서 가상 태블릿을 돌린다. 블루스택과 같은 방식이다.

정직한 구조
HTML 웹사이트 안에 안드로이드 OS를 담아서 무거운 3D 게임을 돌리는 것은 현재 웹 기술로 안 된다. 브라우저는 블루스택처럼 하이퍼바이저와 GPU를 직접 쓸 수 없다. 그래서 실행은 PC 프로그램이 하고, 사이트는 그 프로그램을 받는 곳이다. 연결, Docker, 별도 서버는 이 모드에서 필요 없다.

똥컴에서 하는 순서

  1. 이 레포에서 pc-lite 폴더를 통째로 똥컴에 복사한다.
  2. python lite-check.py 로 RAM, CPU, 디스크를 확인한다.
  3. 구글 공식 Command line tools zip을 받아 같은 폴더에 넣고 setup-lite.bat을 실행한다.
  4. play-lite.bat을 실행한다. 가상 태블릿 에뮬레이터 시작, APK 선택, 설치, 실행, scrcpy 화면 순서로 한다.
  5. Roblox는 에뮬레이터가 필요 없다. 플레이어의 Roblox 버튼은 공식 Windows 클라이언트를 바로 실행한다.

가상 태블릿은 공식 에뮬레이터 태블릿 기기 정의(Nexus 10, 1280x800, RAM 1024MB)를 쓴다. 앱 서버를 속이는 가짜 기기 정보 조작은 하지 않는다.

솔직한 한계

  • 가벼운 2D APK와 Roblox PC 클라이언트는 똥컴에서도 될 가능성이 높다.
  • 브롤 같은 무거운 3D 게임을 에뮬레이터로 고그래픽, 고프레임으로 돌리는 것은 하드웨어 한계로 보장할 수 없다. 켜지고 조작되는 것이 목표다.
  • 별도 서버가 있는 경우에만 docker 폴더를 쓴다. 그 경우에도 이 페이지는 스트리밍 연결판이 아니다.

출처를 모르는 APK는 설치하지 마라. 공식 스토어가 아닌 APK는 악성코드와 계정 정지 위험이 있다.
