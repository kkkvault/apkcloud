내 클라우드 안드로이드 연결

이 페이지는 안드로이드를 직접 돌리지 않는다. 네가 직접 돌리는 서버의 화면으로 연결해주는 연결판이다.

정직한 구조
GitHub Pages는 정적 웹사이트 호스팅이라 안드로이드 에뮬레이터를 돌릴 수 없다. GitHub의 역할은 이 연결판과 서버 코드 보관뿐이다. 실제 안드로이드는 Docker가 있는 리눅스 서버, 또는 가상화가 켜진 PC에서 돌아간다. 똥컴만으로는 무거운 3D 게임용 에뮬레이터를 돌리기 어렵다. 서버가 꺼지면 화면도 멈춘다.

1. 내 서버 주소 연결

주소는 이 기기에만 저장된다. 서버로 보내지 않는다. 같은 와이파이에서는 서버 IP를, 밖에서는 Tailscale 같은 사설 네트워크 주소를 쓴다. 인터넷에 noVNC를 그대로 공개하지 마라.

2. 서버에서 APK 올리는 순서

  1. 서버에 이 레포의 docker/ 폴더를 복사한다.
  2. docker compose up -d 로 안드로이드를 띄우고, 부팅이 끝날 때까지 기다린다.
  3. ./play.sh 네가-받은-파일.apk 를 실행한다. 설치가 끝나면 위 주소로 들어가서 앱 아이콘을 누른다.

출처를 모르는 APK는 설치하지 마라. 공식 스토어가 아닌 APK는 악성코드와 계정 정지 위험이 있다. 브롤 같은 게임은 에뮬레이터 관련 약관 제한이 언급된 적이 있으니 본 계정으로 할 때는 조심해라.

3. 안 되면 먼저 확인할 것

  • 서버에 Docker와 /dev/kvm이 있는가
  • 6080 포트가 서버 방화벽에서 열려 있는가
  • 같은 와이파이가 맞는가, 서버가 켜져 있는가
  • PC에서 돌린다면 BIOS 가상화가 켜져 있는가
