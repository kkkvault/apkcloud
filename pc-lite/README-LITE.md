# PC LITE - 똥컴만으로, 연결 없이, 로컬 가상 태블릿

이 모드는 연결이 없다. 서버 주소도, noVNC도, Docker도 필요 없다.
똥컴에 설치해서 똥컴에서만 돌리는 방식이다. 블루스택과 같은 종류다.
블루스택도 웹사이트 안에 안드로이드가 들어있는 게 아니라,
웹사이트에서 프로그램을 받아서 PC에 설치하고 PC에서 돌리는 것이다.
이 폴더도 똑같다. 사이트는 받는 곳이고, 실행은 PC 프로그램이 한다.

## 가상 태블릿이란

에뮬레이터 가상 기기를 태블릿 형태로 만든 것이다.
공식 에뮬레이터 기기 정의(Nexus 10 태블릿)를 쓰고,
화면을 1280x800, RAM 1024MB, CPU 2코어로 낮춰서 똥컴 부담을 줄였다.
앱 서버를 속이는 가짜 기기 정보 조작은 하지 않는다.
에뮬레이터 탐지를 우회하는 용도로 쓰면 게임 약관 위반이 될 수 있으니,
본 계정으로는 조심해라.

## 준비물: 똥컴 끝

- 똥컴(Windows 10/11, 64비트) 하나면 끝이다.
- 실제 안드로이드 태블릿 필요 없음. 실제 폰 필요 없음. 별도 서버 필요 없음.
- Python 3 (Add to PATH 체크)
- 디스크 여유 10GB 이상
- BIOS 가상화 켜짐 (꺼져 있으면 에뮬레이터가 안 뜬다)

## 순서

1. `python lite-check.py` 로 RAM, CPU, 디스크, 도구 유무를 먼저 확인한다.
2. developer.android.com/studio에서 Command line tools only Windows zip을 받아 이 폴더에 넣는다.
3. `setup-lite.bat`을 더블클릭한다. Android 10 시스템 이미지를 설치하고 `lite` 태블릿 기기를 만든다.
4. `play-lite.bat`을 더블클릭한다. Tkinter 창이 뜬다.
5. 경량 에뮬레이터 시작 -> 기기 확인 -> APK 선택 -> 설치 -> 실행 -> scrcpy 화면(720p 제한) 순서로 한다.
6. Roblox는 에뮬레이터가 필요 없다. 플레이어의 Roblox 버튼은 공식 Windows 클라이언트를 바로 실행한다.

## 솔직한 한계

- 이 구조 변경은 Docker, KVM, 서버 연결이라는 무게를 뺀 것이다. 똥컴에 GPU와 RAM이 생기는 게 아니다.
- 가벼운 2D APK와 Roblox PC 클라이언트는 똥컴에서도 될 가능성이 높다.
- 브롤 같은 무거운 3D 게임을 에뮬레이터로 고그래픽, 고프레임으로 돌리는 것은 하드웨어 한계로 보장할 수 없다. 켜지고 조작되는 것이 목표이고, 버벅이면 그래픽을 낮춰야 한다.
- 웹사이트 HTML 안에 안드로이드 OS 자체를 담아서 무거운 3D 게임을 돌리는 것은 현재 웹 기술로 안 된다. 브라우저는 하이퍼바이저와 GPU를 블루스택처럼 직접 쓸 수 없다.
